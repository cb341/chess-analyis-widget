# Cburnett Chess Pieces

These SVG chess pieces come from Cburnett's Wikipedia chess image set:

<https://en.wikipedia.org/wiki/User:Cburnett/GFDL_images/Chess>

The source page describes the files as available under GFDL, BSD, and GPL
licensing. The demo vendors the SVGs locally so `<chess-widget>` does not make
runtime network requests.
